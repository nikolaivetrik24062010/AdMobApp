# AdMob Android Application (Secure Version)

**AdMob Android Application** is a sample Android project demonstrating the integration of banner and interstitial ads using Google AdMob, implemented with security best practices in mind.

## Features

- **Banner Ads**: Displays a banner ad at the bottom of the screen.
- **Interstitial Ads**: Loads and shows full-screen ads when a button is clicked.
- **Secure Implementation**: Includes safe handling of user data and secure API calls.

## Technologies Used

- **Android SDK**: Platform for developing Android mobile applications.
- **Google AdMob**: Platform for monetizing mobile apps through advertising.
- **Kotlin & Coroutines**: Modern language features for safe and efficient asynchronous handling.
